2. Accessibility Guidelines for NVDA & Screen Reader Users

  • Forms View over Table View: Standard datasheet grid views can be difficult to navigate with screen readers. Creating a form or switching to Form View simplifies data entry field-by-field[cite: 5].
  • Tab Key Navigation: Press the Tab key to move forward efficiently between input fields. Press Shift + Tab to move backward[cite: 5].
  • Section Navigation (F6): Use F6 to cycle focus between major sections of the interface[cite: 5].
  • Return to First Field (Ctrl + Home): Press Ctrl + Home at any time to return focus directly to the first field or record[cite: 5].
  • Table Grid Navigation (Ctrl + Alt + Arrow Keys): Move smoothly up, down, left, and right across cells[cite: 5].

4. Database Queries & Solution Key

Query 1: List all STEM students

Filter Criteria: STEMStudent = 'Y'[cite: 5]

SELECT StudentID, FirstName, LastName, STEMStudent FROM Students WHERE STEMStudent = 'Y';

Expected Output: 1001 – Maya Anderson, 1002 – David Chen, 1004 – Marcus Johnson, 1005 – Priya Patel, 1007 – Min-Jun Kim, 1009 – Carlos Garcia[cite: 5].

Query 2: Students born in 2006

Filter Criteria: DateOfBirth BETWEEN #2006-01-01# AND #2006-12-31#[cite: 5]

SELECT StudentID, FirstName, LastName, DateOfBirth FROM Students WHERE DateOfBirth BETWEEN #2006-01-01# AND #2006-12-31#;

Query 3: Non-STEM students sorted alphabetically

Filter Criteria: STEMStudent = 'N', Sorted by LastName ASC, FirstName ASC[cite: 5]

SELECT StudentID, LastName, FirstName, STEMStudent FROM Students WHERE STEMStudent = 'N' ORDER BY LastName ASC, FirstName ASC;
