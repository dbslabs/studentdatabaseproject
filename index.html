2. Accessibility Guidelines for NVDA & Screen Reader Users

  • Forms View over Table View: Standard datasheet grid views can be difficult to navigate with screen readers. Creating a form or switching to Form View (Right-click table name -> 'Edit' or open via Form Design) simplifies data entry field-by-field[cite: 1].
  • Tab Key Navigation: Press the Tab key to move forward efficiently between input fields. Press Shift + Tab to move backward[cite: 1].
  • Section Navigation (F6): Use F6 to cycle focus between major sections of the interface (Navigation Pane, Main Workspace, and Status Bar)[cite: 1].
  • Return to First Field (Ctrl + Home): Press Ctrl + Home at any time to return focus directly to the first field or record[cite: 1].
  • Table Grid Navigation (Ctrl + Alt + Arrow Keys): If navigating in grid view, use Ctrl + Alt + Arrow keys to move smoothly up, down, left, and right across cells[cite: 1].

Query 1: List all STEM students

Filter Criteria: STEMStudent = 'Y'[cite: 1]

SQL Statement:
