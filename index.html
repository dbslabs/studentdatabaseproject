Student Database Project

Instructions, Accessible Data Format & Query Solution Key

1. Project Overview & Table Setup

This project involves creating a student relational database, entering student records, and executing targeted queries. Follow the accessibility standards and field specifications below to set up your table[cite: 5].

Field Specifications:

  • StudentID: Number (Integer) - Unique Student Identification Number - Primary Key: Yes[cite: 5]
  • LastName: Short Text - Student Last Name - Primary Key: No[cite: 5]
  • FirstName: Short Text - Student First Name - Primary Key: No[cite: 5]
  • DateOfBirth: Date/Time - Format: YYYY-MM-DD or Short Date - Primary Key: No[cite: 5]
  • MailingAddress: Short Text / Long Text - Full address (Street, City, State, ZIP) - Primary Key: No[cite: 5]
  • STEMStudent: Short Text or Yes/No - 'Y' / 'N' or Boolean Checkbox - Primary Key: No[cite: 5]
  • Hobbies: Short Text / Long Text - List of student hobbies and interests - Primary Key: No[cite: 5]

2. Accessibility Guidelines for NVDA & Screen Reader Users

  • Forms View over Table View: Standard datasheet grid views can be difficult to navigate with screen readers. Creating a form or switching to Form View (Right-click table name -> 'Edit' or open via Form Design) simplifies data entry field-by-field[cite: 5].
  • Tab Key Navigation: Press the Tab key to move forward efficiently between input fields. Press Shift + Tab to move backward[cite: 5].
  • Section Navigation (F6): Use F6 to cycle focus between major sections of the interface (Navigation Pane, Main Workspace, and Status Bar)[cite: 5].
  • Return to First Field (Ctrl + Home): Press Ctrl + Home at any time to return focus directly to the first field or record[cite: 5].
  • Table Grid Navigation (Ctrl + Alt + Arrow Keys): If navigating in grid view, use Ctrl + Alt + Arrow keys to move smoothly up, down, left, and right across cells[cite: 5].
