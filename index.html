Instructions, Accessible Data Format & Query Solution Key

1. Project Overview & Table Setup

This project involves creating a student relational database, entering student records, and executing targeted queries. Follow the accessibility standards and field specifications below to set up your table.

Field Specifications

Table listing database fields, their data types, descriptions, and primary key status.
Field Name Data Type Description / Format Primary Key
StudentID Number (Integer) Unique Student Identification Number Yes
LastName Short Text Student Last Name No
FirstName Short Text Student First Name No
DateOfBirth Date/Time Format: YYYY-MM-DD or Short Date No
MailingAddress Short Text / Long Text Full address (Street, City, State, ZIP) No
STEMStudent Short Text or Yes/No 'Y' / 'N' or Boolean Checkbox No
Hobbies Short Text / Long Text List of student hobbies and interests No

2. Accessibility Guidelines for NVDA & Screen Reader Users

  • Forms View over Table View: Standard datasheet grid views can be difficult to navigate with screen readers. Creating a form or switching to Form View (Right-click table name -> 'Edit' or open via Form Design) simplifies data entry field-by-field.
  • Tab Key Navigation: Press the Tab key to move forward efficiently between input fields. Press Shift + Tab to move backward.
  • Section Navigation (F6): Use F6 to cycle focus between major sections of the interface (Navigation Pane, Main Workspace, and Status Bar).
  • Return to First Field (Ctrl + Home): Press Ctrl + Home at any time to return focus directly to the first field or record.
  • Table Grid Navigation (Ctrl + Alt + Arrow Keys): If navigating in grid view, use Ctrl + Alt + Arrow keys to move smoothly up, down, left, and right across cells.

4. Database Queries & Solution Key

Filter Criteria: STEMStudent = 'Y'

SQL Statement:

SELECT StudentID, FirstName, LastName, STEMStudent FROM Students WHERE STEMStudent = 'Y';
